Privacy Policy Last updated: 2026 This application is a personal tool built and used solely by its developer to post their own video content to their own TikTok account. It is not distributed to or used by any other individuals. What data this app accesses This app uses TikTok's Content Posting API, with the video.upload scope, solely to send video files to the developer's own TikTok account inbox for the developer to review and publish. No data belonging to any other TikTok user is accessed, collected, or stored. What data this app stores This app stores an OAuth access token and refresh token locally on the developer's own computer, used only to authenticate requests to the developer's own TikTok account. This data is never transmitted to any third party or server other than TikTok's own API. Contact Questions about this policy can be directed to the developer via their TikTok developer account.
